# 📋 Kanban Board

A responsive task management board that allows users to organize tasks into different stages using an interactive and easy-to-use interface.

## ✨ Features

* Create and organize tasks
* Move tasks between different stages
* Interactive task management
* Clean and user-friendly interface
* Responsive design
* Dynamic JavaScript functionality

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📱 Responsive Design

The Kanban Board is designed to work across:

* Desktop
* Tablet
* Mobile
